# Apache Superset Integration Guide

## Обзор

Apache Superset используется как основной инструмент для аналитики и визуализации данных в Unified Data Dashboard System (UDDS). Эта интеграция позволяет использовать всю мощь Superset для анализа данных, загружаемых из Google Sheets.

## Архитектура интеграции

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Google Sheets │────│   UDDS Backend  │────│   PostgreSQL    │
│                 │    │   (FastAPI)     │    │                 │
└─────────────────┘    └─────────────────┘    └────────┬────────┘
                                                       │
                                                       │
┌─────────────────┐    ┌─────────────────┐    ┌────────▼────────┐
│   UDDS Frontend │────│   Apache        │────│   Superset      │
│   (React)       │    │   Superset      │    │   Metadata DB   │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

## Компоненты интеграции

### 1. Конфигурация Superset (`superset_config.py`)
- Настройки подключения к PostgreSQL
- Конфигурация кеширования Redis
- Настройки безопасности и CORS
- Конфигурация дополнительных баз данных

### 2. Docker Compose конфигурация
- Кастомный Dockerfile для Superset
- Скрипт инициализации
- Health checks и зависимости

### 3. API интеграция (`backend/app/api/superset.py`)
- Проверка статуса Superset
- Создание дашбордов
- Создание чартов
- Синхронизация датасетов

### 4. Скрипты автоматизации
- `superset_init.sh` - инициализация Superset
- `create_superset_dashboards.py` - создание дашбордов

## Автоматические дашборды

Система автоматически создает следующие дашборды:

### 1. UDDS Analytics Dashboard
Основной дашборд с ключевыми метриками:

#### Charts:
1. **Records Over Time**
   - Тип: Line chart
   - Метрика: Количество записей
   - Группировка: По дням
   - Назначение: Отслеживание динамики поступлений

2. **Records by Source**
   - Тип: Bar chart
   - Метрика: Количество записей
   - Группировка: По источнику
   - Назначение: Анализ источников данных

3. **Spam vs Non-Spam Records**
   - Тип: Pie chart
   - Метрика: Количество записей
   - Группировка: По статусу спама
   - Назначение: Анализ качества данных

4. **Top Categories**
   - Тип: Table
   - Метрика: Количество записей
   - Группировка: По категориям
   - Назначение: Топ категорий обращений

5. **Records by Status**
   - Тип: Bar chart
   - Метрика: Количество записей
   - Группировка: По статусу
   - Назначение: Анализ статусов обращений

## API Endpoints

### Проверка статуса
```bash
GET /api/v1/superset/status
```
Проверяет подключение к Superset и возвращает статус.

### Создание дашборда
```bash
POST /api/v1/superset/dashboards/create
```
Создает новый дашборд в Superset.

**Request body:**
```json
{
  "title": "Анализ обращений",
  "description": "Дашборд для анализа обращений граждан",
  "dataset_id": "community_requests",
  "charts": [
    {
      "title": "Обращения по дням",
      "viz_type": "line",
      "metrics": [{"label": "COUNT(*)"}],
      "groupby": []
    }
  ]
}
```

### Получение дашбордов
```bash
GET /api/v1/superset/dashboards/{dataset_id}
```
Возвращает список дашбордов для указанного датасета.

### Создание чарта
```bash
POST /api/v1/superset/charts/create
```
Создает новый чарт в Superset.

### Синхронизация датасетов
```bash
GET /api/v1/superset/datasets/sync
```
Синхронизирует все датасеты с Superset (создает подключения к БД).

## Настройка Superset

### Переменные окружения
```bash
# В .env файле
SUPERSET_SECRET_KEY=your-secret-key-here
SUPERSET_DATABASE_PASSWORD=your-password-here
```

### Конфигурация базы данных
Superset использует две базы данных:
1. **Superset Metadata DB** - для хранения метаданных Superset
2. **UDDS PostgreSQL** - для доступа к данным приложения

### Инициализация
При первом запуске Superset:
1. Создается база данных метаданных
2. Создается административный пользователь (admin/admin)
3. Настраивается подключение к UDDS PostgreSQL
4. Создаются базовые дашборды

## Расширение функциональности

### Добавление новых типов чартов
1. Отредактируйте `create_superset_dashboards.py`
2. Добавьте новый тип чарта в функцию `create_chart`
3. Обновите дашборд для включения нового чарта

### Кастомные дашборды
1. Используйте Superset UI для создания дашбордов
2. Экспортируйте дашборд в JSON
3. Импортируйте через API или вручную

### Интеграция с другими источниками данных
1. Добавьте новое подключение к БД в `superset_config.py`
2. Настройте доступ в Superset UI
3. Создайте дашборды для нового источника

## Устранение неполадок

### Superset не запускается
1. Проверьте логи: `docker-compose logs -f superset`
2. Убедитесь, что PostgreSQL запущен
3. Проверьте переменные окружения

### Нет доступа к данным
1. Проверьте подключение к UDDS PostgreSQL
2. Убедитесь, что таблица `records` существует
3. Проверьте права доступа пользователя Superset

### Дашборды не создаются
1. Проверьте скрипт `create_superset_dashboards.py`
2. Убедитесь, что Superset API доступен
3. Проверьте логи инициализации

## Безопасность

### Рекомендации для production
1. Измените пароль администратора
2. Настройте ролевую модель доступа
3. Включите аутентификацию через OAuth
4. Настройте SSL/TLS для Superset
5. Ограничьте доступ к порту 8088

### Переменные окружения для безопасности
```bash
SUPERSET_SECRET_KEY=strong-random-key-here
SUPERSET_DATABASE_PASSWORD=strong-password-here
ENVIRONMENT=production
```

## Заключение

Интеграция с Apache Superset предоставляет мощный инструмент для аналитики данных, загружаемых из Google Sheets. Система автоматически настраивает подключения, создает базовые дашборды и предоставляет API для управления аналитикой.

Для расширения функциональности используйте богатые возможности Superset:
- Создание кастомных дашбордов

- Интеграция с другими источниками данных
